# Детка Плюс — аудит и визуальная концепция

17 ноября 2026 года. Визуальная концепция с правками после просмотра владельцем.

## Что мешало первому впечатлению

1. Утверждённый логотип уже находился в проекте, но сайт продолжал показывать текстовую замену и сообщение об отсутствии исходника.
2. Большая арка с геометрическими растениями занимала место содержательного изображения. SVG-веточка не соответствовала запросу на акварельную полиграфию.
3. Все разделы имели почти одинаковую структуру, цвет карточек менялся без смысловой причины. Впечатление строилось на декоре, а не на характере центра.
4. Georgia и Arial, мелкие подписи и отсутствие настоящих фотообразов делали страницу похожей на общий шаблон.
5. Open Graph использовал SVG; для карточек ссылок подготовлен растровый PNG. Локальный preview мог незаметно показывать старый релиз вместо проверяемой сборки.

## Что реализовано

- Современная типографика: Manrope для интерфейса, контрастный курсив Cormorant для эмоциональных акцентов. Кириллица и латиница в локальных WOFF2; лицензии сохранены.
- Крупный первый экран: двухчастный заголовок, фотообраз взаимодействия, акварельные орнаменты с прозрачностью по боковым полям. Основное действие — обратный звонок для знакомства.
- Кремовый, сиреневый, мятный и малиновый сохранены. Тёмный фон раздела о подходе убран по замечанию владельца. Ориентир для фонов — нежный кремово-сиренево-мятный градиент формы обратного звонка.
- Разная композиция разделов главной: карточки запросов, светлый градиентный блок принципов, компактное знакомство с командой, фото и контакты в двух колонках.
- Утверждённый логотип в шапке, подвале, favicon и социальной карточке. Исходный PNG сохранён побайтно; копии 96 / 192 / 384 px оптимизированы.
- Два фотореалистичных ИИ-изображения созданы по прямому запросу владельца для примера. Они явно подписаны как образы для макета. Они не подтверждают личность сотрудника, внешний вид центра или реально оказываемую услугу.
- В галерее показываются фотообразы с пояснением, а не декоративная ветка под видом галереи центра.
- Для мобильного экрана композиция собирается вертикально; меню, ссылки и форма сохраняют рабочие действия. Декоративный слой не перехватывает нажатия.
- Основной контент остаётся в статическом HTML. Уникальные SEO-поля, canonical, JSON-LD и sitemap сохранены; в JSON-LD добавлен логотип, OG переведён на PNG с размерами и описанием.

## Границы первого прохода

Из связанного чата прочитан текстовый контекст и просмотрены три доступных скриншота. Самой старой визитки среди доступных вложений нет. Поэтому акварель создана по описанию, соответствие конкретному рисунку визитки не заявляется.

Не добавлены вымышленные специалисты, квалификации, услуги, отзывы, телефон и часы работы. Демоматериалы и запрет индексации черновика сохранены. Для рабочего сайта нужны утверждённые тексты, данные команды, реквизиты и материалы центра.

Архитектура Nuxt SSG → снимок SQLite, отдельный backend и контролируемая публикация сохранена. Сохранённый релиз не переключался. `STATIC_ROOT=frontend/.output/public yarn preview` позволяет смотреть новый результат отдельно от него; браузерная проверка использует этот же путь.

Источники и назначение изображений: `frontend/public/images/README.md`.
